# usage-buddy

> 入力欄の上の小さな相棒が、Claudeの使用枠の残りをそっと教えてくれる。

`usage-buddy` は [Claude Code](https://docs.claude.com/en/docs/claude-code) 用のMod（プラグイン）です。入力欄のすぐ上・右端に、Claude風の小さなマスコットと、その下に **5時間枠の残り%とリセットまでの時間** を表示します。

```
 ▐▛███▜▌
▝▜█████▛▘
  ▘▘ ▝▝
93%/4h51m
```

## 作った理由

VS Codeを縦に三分割してその1つでClaude Codeを動かしていると、横長のステータス表示は切れたり折り返したりして読みづらくなります。usage-buddyはその使い方を前提に作りました。幅はわずか10セル、折り返さず、「まだ続けられるか／そろそろ控えるべきか」が一目で分かります。

## 特徴

- **狭いペインでも崩れない**: マスコットと数字は幅10セル固定の列に収まります（最長の `100%/4h59m` がちょうど10セル）。行は折り返しません。ペインの幅が10セル未満のときは何も描画しません。
- **クリックで詳細を開閉**: 数字をクリックすると、5時間枠（小さなバー付き）・週間枠・コンテキスト使用率の詳細が開きます。もう一度クリックで閉じます。
- **色で気分を表現**: 使用率が上がるとマスコットの体の色が変わり、ピンチになると半目になります。
- **テーマに追従**: 色はClaude Codeのテーマ色（`claude` / `warning` / `error`）を使うので、ライト・ダーク・色覚配慮テーマに合わせて変わります。

### 状態別の見た目

マスコットの気分は「5時間枠・週間枠・コンテキスト」のうち **最も高い使用率** で決まります。数字の色は5時間枠だけで決まります。

| 使用率 | 体の色 | 目 | 見た目 |
|---|---|---|---|
| 60%未満 | Claudeオレンジ | 通常 | ` ▐▛███▜▌` |
| 60%以上85%未満 | 黄（warning） | 通常 | ` ▐▛███▜▌` |
| 85%以上 | 赤（error） | 半目 | ` ▐▀███▀▌` |

リセット時刻を過ぎた枠は、次の応答で新しい値が届くまで0%として扱います。

### 詳細表示（開いたとき）

```
 ▐▛███▜▌
▝▜█████▛▘
  ▘▘ ▝▝
93%/4h51m
5時間 █░░░░░░░ 残93% 4時間51分後
週間 残71% 3日2時間後
ctx 24%
```

## インストール

**ターミナル** で起動したClaude Codeの入力欄に、次の1行を入力します。

```
/plugin install usage-buddy --marketplace Surigoma001/claude-usage-buddy
```

続いて:

1. `Add marketplace?`（ソース `github:Surigoma001/claude-usage-buddy`）と聞かれたら `y` を入力します。
2. スコープを選びます。先頭にあるユーザースコープのままEnterを押すと、すべてのセッションで有効になります。
3. `Installed usage-buddy. Plugin is now active.` と表示されれば完了です。マスコットはそのセッションでClaudeが最初に応答した後に表示されます。

すでにこのマーケットプレイスを追加済みの場合、手順1は省略されます。

## 更新・アンインストール

最新版に更新:

```
claude plugin update usage-buddy@claude-usage-buddy
```

その後Claude Codeを再起動するか、開いているセッションで `/reload-plugins` を実行してください。

アンインストール:

```
claude plugin uninstall usage-buddy@claude-usage-buddy
```

マーケットプレイスの登録も消す場合:

```
claude plugin marketplace remove claude-usage-buddy
```

## 要件・制限

- **サブスク契約（Pro / Max）のときのみ**: 5時間枠・週間枠は、Claudeのサブスクリプションでログインしているときだけ取得できます。API従量課金にはこの枠がないため、マスコットだけが表示され、数字は出ません。数字がクリック対象なので、詳細表示も開けません（コンテキスト使用率に応じた体の色の変化は動きます）。
- **最初の応答までは表示されない**: 数値はAPIの応答から得るため、セッション内でClaudeが1回応答するまでは表示されません。
- **クレジット残高は表示できない**: クラウド／APIのクレジット残高はClaude Codeが提供するデータに含まれないため、表示できません。
- **VS Codeでは統合ターミナルで使う**: VS Codeの統合ターミナルでCLIとしてClaude Codeを動かす場合に動作します。VS Code拡張のチャットパネルには表示されません。
- **クリックはフルスクリーン表示時のみ効く可能性あり（未確認）**: ターミナルでのマウスクリックは、Claude Codeのフルスクリーン表示モードでのみModに届く可能性があります。未検証です。クリックが効かなくても、数字の表示自体は使えます。
- **デスクトップアプリ: 未検証**: 公式ドキュメント上は、ユーザースコープでインストールしたModはデスクトップアプリのローカルCodeセッションでも読み込まれますが、このModはそこでは未検証です。
- **インストールコマンドはターミナル専用**: `/plugin install` はデスクトップアプリのCodeタブでは使えません。ターミナルのセッションから実行してください。

## カスタマイズ

すべて [`hooks/register.tsx`](./hooks/register.tsx) にあります。リポジトリをフォークして編集し、手元のコピーを読み込んでください（[開発・テスト](#開発テスト) 参照）。

| 変えたいもの | 場所 |
|---|---|
| 気分ごとの色 | `BODY`（テーマ色名: `claude`, `warning`, `error` など） |
| 気分ごとの目 | `EYES`（左右の目の文字） |
| しきい値（60% / 85%） | `moodOf` |
| 列の幅 | `MASCOT_WIDTH`（既定 `10`。これ未満の幅では何も描画しない） |
| マスコットの形 | `ui.render` フック末尾近くの3行の `<Text>` |
| 詳細表示の文言・言語 | `details.push(...)` の行と `until` 関数 |

マスコットや数字の書式を変える場合は、狭いペインで折り返さないよう、各行を `MASCOT_WIDTH` セル以内に収めてください。

## 開発・テスト

```
git clone https://github.com/Surigoma001/claude-usage-buddy.git
cd claude-usage-buddy

claude plugin validate .   # マーケットプレイスファイル・マニフェスト・フックモジュールを検査
claude plugin test .       # tests/*.test.tsx をエンジン上で実行
claude --plugin-dir .      # インストールせずにセッションで試す
```

構成:

```
.claude-plugin/
  marketplace.json   # このリポジトリをマーケットプレイスにする（source "./"）
  plugin.json        # Modのマニフェスト
hooks/
  hooks.json         # register.tsx を指す
  register.tsx       # Mod本体
types/index.d.ts     # 状態の型定義
tests/band.test.tsx  # テスト
```
